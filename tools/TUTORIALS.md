# チュートリアル面の案

各ゲームの先頭に置く「ふつうとの違いを1面で1つ分かる」面の案。
**ここにあるのは案**で、最終的な形は編集モードで手直しする前提。

書き方は XSB。`#`壁 空白床 `.`置き場 `$`荷物 `*`置き場の上の荷物
`@`自機 `+`置き場の上の自機 `~`水 / 印あわせは印つきの荷物`1-9`・印つきの置き場`a-i`。
春は `@` を2つ書く(左上から数えて1匹目・2匹目。1匹目から始まる)。

面をパックに入れるときは `warehouse/packs/<名前>-tutorial.json` に書き、
`node tools/build-pack.js <名前>` で本編とつなぐ。手書きのファイルは生成器が
触らないので、生成器を回しても消えない。

---

## 春 🐝 2匹のミツバチ

覚えることは3つ。「交代する」「待つほうは壁」「押した先に居残る」。
手数はどれも `warehouse/rules.js` の duo で検算ずみ。

### 第1課 — 1回押すと交代する

```
#####
#@  #
# $@#
#  .#
#   #
#####
```
2匹ルール 2手 / ふつう1匹でも 2手

1匹目が下へ1回押すと、そこで番が終わる。残りの1押しは2匹目の仕事になる。
**手数はふつうと同じ**なので、増えた難しさはなく、「勝手に交代する」ことだけが分かる。
1匹目は押した場所に残るので、2匹目はぐるっと回って反対側へ行くことになる。

### 第2課 — 待っているほうは壁

```
######
#@  ##
#    #
# $@.#
#    #
######
```
2匹ルール 4手 / ふつう1匹なら 2手

置き場のすぐ手前に2匹目が立っている。1匹だけなら右に2回押して終わりだが、
2匹目が壁なのでその道は通れない。上へ逃がして回り込むことになり、2手が4手に増える。
**「相方はどけられない壁だ」**が、手数の差でそのまま伝わる。

### 第3課 — 押したミツバチはその場に残る

```
######
# @  #
#  $ #
#.$ ##
#@ . #
######
```
2匹ルール 5手 / ふつう1匹なら 3手

荷物が2つあり、どちらをどちらのミツバチに押させるかで詰まる。
押した側は荷物のいた場所に居残って壁になるので、**押す向きを選ぶとき、
自分がどこに残るかまで考える**必要がある、という面。

### 補足 — この案をそのまま使うときの注意

- 第1課は「ふつうと同じ手数」なので、生成器の重複よけ(`MATTERS`)を
  切って探した。本編用の面としては採らない種類の面で、チュートリアル専用。
- 3面とも荷物が少なく盤も小さいので、詰んでも数手で戻れる。
- 交代が分かりにくいようなら、第1課の2匹をもっと離すと、
  「押したら向こうのハチが光る」がはっきりする。
