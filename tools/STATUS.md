## 引っ越し

別の端末へ記録を持っていく仕組み。**右下の「📋履歴」→「📦 別の端末に引っ越す」**。
（最初はデバッグ表示の中に置いていたが、普通に遊ぶ人が使う機能なので履歴の中へ移した）
リンクを新しい端末で開くと入る。貼り付け欄もある。

**IDを並べ替えた順**を土台にしているので、面を並べ替えても壊れない。
上書きせず合流する（クリア手数は少ないほうが残る／手こずり具合は
こちらに無い面だけ入れる。手元の記録のほうが確かなので上書きしない）。
取り込む前に必ず聞く。面ぞろえの指紋が違う端末は弾く。
`?move=…` は取り込んだあと URL から消すので、再読込で二度聞かれない。

### 何を載せて、何を載せないか（2026-08-18 に本人が決めた）

| 保存されるもの | リンクに載せる |
|---|---|
| クリア記録（面ID → 自己ベストの押し回数） | **載せる** |
| 手こずり具合 | **載せる**（簡素化して） |
| 着せ替え | **載せる** |
| 十字キーの大きさ | **載せる** |
| デバッグ表示 / ★ / ✕ / 協力プレイの負け | **載せない** |

手こずり具合は、リンクには次の形で載る。無い項目は書かない。

```
印(2ビット) + 初回に解けた押し数(6ビット、最短との差)
印≧1 なら + それまでのやり直し回数(4ビット)
印≧2 なら + その後、最短に届くまでの失敗回数(4) とやり直し回数(4)
```

最初から最短で解けた面は印0で8ビットしか使わない。
（端末の中では `u` 戻した回数と `s` 秒数も持っているが、リンクには載せない）

## この環境で踏んだ罠

- **作業環境が何度も巻き戻る。** コミットしていない変更は消える。
  戻ったら `git fetch origin && git checkout -B <branch> origin/main` で復帰。
  **こまめにコミットしてプッシュすること**
- **`/tmp` は消える。** 時間のかかる計算の控えは必ずリポジトリの中（`tools/stock/`）に置く
- **同時に何本も走らせるときは、控えを担当ごとに別ファイルにすること。**
  1つのファイルを読んで書き足す形にすると、後から書いたほうが前のを丸ごと消す。
  回り込みの測定で実際に132面ぶん消えた。`verify-levels.js` と
  `scan-latewalk.js` は担当ごとに分けて、読むときだけ混ぜる形に直してある
- **検証は控えが効いて0.0秒で終わる。** 並べ替えのあとは必ず
  `SHARDS=1 node tools/verify-levels.js` を回して確かめること
